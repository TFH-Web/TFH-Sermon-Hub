# TFH-621 verification and handoff

Date: 2026-10-23
Branch: givin-sprint8/integration

## Implemented

- Shared YouTube link validation and watch/embed/source builders.
- Validation of saved video links against stored YouTube IDs.
- Valid older links remain usable when no stored ID exists.
- Sermon detail Watch and metadata links use canonical validated URLs.
- Transcript source links use validated IDs.
- Invalid or mismatched records retain readable sermon/transcript content
  without a player or clickable video/source links.
- Embedded seeking preserves fractional seconds.
- External source URLs use whole seconds, matching TFH-600.
