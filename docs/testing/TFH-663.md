# TFH-663: Coverage minimum enforcement

## Implementation

- Frontend: enforce overall minimums of 55% lines and 55% branches.
- Include untested production files.
- Exclude test files, declarations and src/test helpers.
- Backend: enforce 90% lines and 80% branches independently.
- Fail backend validation when the report is missing or invalid.
- Preserve coverage summaries and report uploads in CI.

## Local verification

- Frontend: 476 tests passed across 39 files.
- Frontend lines: 63.89%, above the 55% minimum.
- Frontend branches: 62.89%, above the 55% minimum.
- Backend: 1,165 tests passed; 3 snapshots passed.
- Backend lines: 95.92%, above the 90% minimum.
- Backend branches: 89.89%, above the 80% minimum.
- Backend checker returned exit code 0 for the actual report.
- Production build passed.
