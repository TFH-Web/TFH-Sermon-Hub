# TFH-628 summary-origin verification

## Current contract after merging dev / PR #140

The earlier 2026-10-24 results below are historical. PR #140 supersedes the
earlier rule that preserved AI origin after a manual summary save:

- Successful AI generation stores `summarySource: "ai"`.
- An explicit nonblank manual summary save stores `"manual"`, including edits
  to an AI summary; the AI label disappears after the successful response.
- Clearing the summary or changing its video clears the origin.
- Metadata-only edits preserve origin; failed saves, failed regeneration and
  Cancel preserve the previous content and origin.
- Legacy unknown origin remains null. Client-supplied origin is ignored.

The frontend retains the shared `SermonSummaryOrigin` component and the
`AI Generated` label casing. Component tests, backend contract tests and browser
tests now assert the merged contract. Recheck the changed manual-save rule
against the real local backend and private staging before recording acceptance.
